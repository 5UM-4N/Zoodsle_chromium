Keyboard Shortcuts

ZoodSle supports fast, accessible keyboard navigation on any webpage. You can also rebind or customize these shortcuts directly in Chrome at chrome://extensions/shortcuts.

Action macOS Shortcut Windows / Linux
Describe focused or active photo ⌥ + ⇧ + D (Option+Shift+D) Alt + Shift + D

Privacy & Local Processing

100% Local Inference: Every image analyzed by ZoodSle is processed by your local machine using qwen/qwen3-vl-4b in LM Studio. No photos, descriptions, or conversation logs are sent to cloud services, external AI providers, or remote analytics.

Permissions: ZoodSle requires access to http://127.0.0.1:8000/* to communicate with the local vision backend, and standard web host permissions to inspect images on any webpage and display audio descriptions.
